ACS ZCTA Panel Data Description

File name: acs_zcta_panel.csv
Unit of observation: ZIP Code Tabulation Area (ZCTA) by Year
Time coverage: 2012 - 2026 (Annual longitudinal panel)
Source: U.S. Census Bureau, American Community Survey (ACS) 5-year estimates

Variables:
1. NAME: Full geographic name of the ZCTA (e.g., "ZCTA5 00601").
2. Median_Household_Income: Median household income in the past 12 months (in inflation-adjusted USD). ACS Variable: B19013_001E.
3. Median_Real_Estate_Taxes: Median real estate taxes paid on owner-occupied housing units. ACS Variable: B25103_001E.
4. Median_Home_Value: Median value of owner-occupied housing units. ACS Variable: B25077_001E.
5. state: State FIPS code associated with the ZCTA.
6. ZCTA: 5-digit ZIP Code Tabulation Area identifier.
7. year: The survey year or forward-filled year for the observation.
8. Effective_Property_Tax_Rate: Calculated as Median_Real_Estate_Taxes divided by Median_Home_Value.

Note on Methodology:
- Data for 2012-2024 were derived from the respective ACS 5-year rolling estimates.
- Data for 2025 and 2026 were constructed by carrying forward the 2024 estimates.

Macroeconomic ZCTA Panel Data Description

File name: macro_zcta_panel.csv
Unit of observation: ZIP Code Tabulation Area (ZCTA) by Year
Time coverage: 2012 - 2026 (Annual longitudinal panel)
Source: Bureau of Economic Analysis (BEA) and Bureau of Labor Statistics (BLS)

Variables:
1. ZCTA: 5-digit ZIP Code Tabulation Area identifier.
2. year: The data year or forward-filled year for the observation.
3. Real_GDP_per_capita_ZCTA: Real GDP per capita (in chained dollars), calculated at the county level and mapped to ZCTAs as a regional environmental indicator.
4. Unemployment_Rate_ZCTA: Estimated local unemployment rate, calculated at the county level and mapped to ZCTAs.

Note on Methodology:
- Variable Type: Both GDP per capita and Unemployment are treated as Intensive Regional Environment variables.
- Calculation: Real GDP per capita is derived by fetching Total Real GDP (BEA CAGDP9) and County Population (BEA CAINC1), then dividing.
- Mapping: Macroeconomic conditions are assigned to ZCTAs based on residency allocation factors (afact from MCDC Geocorr 2022).

Geospatial Border Distance Panel Data Description

File name: zcta_distance_panel.csv
Unit of observation: ZIP Code Tabulation Area (ZCTA) by Border Dyad
Source: U.S. Census Bureau (TIGER/Line Shapefiles)

Variables:
1. zcta: 5-digit ZIP Code Tabulation Area identifier.
2. stab: Two-letter state abbreviation of the ZCTA.
3. border_dyad: Identifier for the state-to-state border dyad (e.g., "VA-WV").
4. S_i: Binary treatment indicator (Si = 1 if the ZCTA belongs to the alphabetically first state in the dyad, Si = 0 otherwise).
5. dist_km: Shortest Euclidean distance from the ZCTA centroid to the specific border segment.
6. d_ic: Signed distance to the border (dic = dist_km if Si = 1, dic = -dist_km if Si = 0).

IPEDS Tuition Panel Data Description

File name: ipeds_tuition_panel.csv
Unit of observation: State by Year (2012-2026)
Source: NCES IPEDS

Note on Methodology:
- Sample Restriction: 4-year public, degree-granting universities (control=1, iclevel=1, hloffer>=5, deggrant=1). 
- Weights: In-state tuition weighted by FTFT in-state students (scfa12n); out-of-state tuition weighted by FTFT out-of-state students (scfa13n).

Redfin Zip-Code Housing Panel Data Description

Master DiDC Spatial Panel Data Description

File name: master_didc_panel.csv
Unit of observation: ZCTA by Year by Border Segment
Time coverage: 2012 - 2026
Source: Integrated Panel (ACS, Macro, IPEDS, US News, Redfin, Border Distance)

Purpose: The final integrated dataset for spatial Difference-in-Discontinuities analysis of public university policy shocks.

Key Variables:
1. border_dyad: The specific state pair (e.g., "NC-VA").
2. segment_id: High-resolution border segment identifier.
3. S_i: Strategic side indicator (1 = Alphabetic First, 0 = Second).
4. d_ic: Signed distance to border (Positive for S_i=1).
5. delta_in_state_tuition: Policy Gap (State A tuition - State B tuition).
6. delta_top_100_caliber: Caliber Gap (State A Top 100 count - State B Top 100 count).
7. interaction_tuition: Core DiDC variable (S_i * delta_in_state_tuition).
8. interaction_caliber: Core DiDC variable (S_i * delta_top_100_caliber).
9. ln_median_ppsf: Outcome (Log of Median Price Per Square Foot).
10. ln_real_gdp_pc: Control (Log of Real GDP per capita).

Note on Methodology:
- Integration: Merges the spatial segmentation (zcta_distance_segment_panel) with longitudinal ZCTA-year controls and housing outcomes.
- Dyadic Gaps: Policy gaps are calculated for each year and each state pair to capture the time-varying shock intensity.
- Dimensional Expansion: ZCTAs near multiple borders are duplicated across dyads to contribute as local controls for each specific policy discontinuity.

Estimation Sample Panel Data Description

File name: estimation_didc_panel.csv
Unit of observation: ZCTA by Year by Border Segment
Time coverage: 2012 - 2026
Source: Integrated Master Panel with MSE-Optimal Bandwidth Selection (rdbwselect)

Purpose: The finalized regression-ready dataset, restricted to observations within the state-border "bandwidth of indifference" as determined by local polynomial optimization.

Key Variables:
1. h_star: Localized MSE-optimal bandwidth (in km) calculated via rdrobust (Calonico et al., 2014) for each specific border segment based on baseline year home values.
2. Estimation_Sample: Binary indicator (1 = Observation is within h_star of the border; 0 = Observation is excluded).
3. All prior variables from master_didc_panel.csv (Deltas, Interactions, Log-Outcomes).

Note on Methodology:
- Bandwidth Selection: For each border segment, an optimal spatial bandwidth (h*) is estimated using the MSE-optimal selector on the 2012 baseline cross-section of Log Median Home Value. 
- Hierarchical Fallback: If a segment has insufficient observations (<15 per side), the optimization falls back to the parent border dyad's h*. 
- Sample Size: The finalized estimation sample (Estimation_Sample=1) contains 448,941 observations (16.3% of the master pool), ensuring that the DiDC analysis focuses strictly on the geographic discontinuities.
- Longitudinal Projection: h* calculated in 2012 is applied statically throughout the 2012-2026 panel to ensure a balanced, time-invariant geographic sample across the treatment horizon.

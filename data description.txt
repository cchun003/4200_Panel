# IPEDS Tuition Panel Data Description

## Overview
The `ipeds_tuition_panel.csv` file provides a longitudinal state-level panel (2012–2026) of enrollment-weighted average tuition for public institutions in the United States.

## Data Fetching Process
The raw data is programmatically extracted from the National Center for Education Statistics (NCES) Integrated Postsecondary Education Data System (IPEDS) using the `ipeds` R package. For each year in the 2012–2024 period, the extraction script (`task_0.1_ipeds.R`) retrieves and dynamically joins three primary survey components:

1. **HD (Institutional Characteristics Header):** Used to identify the institution's state abbreviation (`STABBR`), FIPS code, and control type (Public vs. Private).
2. **IC_AY (Student Charges - Academic Year):** Used to retrieve the base tuition rates for in-state undergraduates (`tuition2`) and out-of-state undergraduates (`tuition3`).
3. **SFA (Student Financial Aid - Part 1):** Used to retrieve the number of first-time, full-time (FTFT) degree/certificate-seeking undergraduates paying in-state tuition (`scfa12n`) vs. out-of-state tuition (`scfa13n`).

## Derivation of Weights
Weights are applied to create representative state-level averages that account for the distribution of students across institutions of varying sizes.

- **In-State Tuition Weighting:** The state-level in-state tuition is the enrollment-weighted average of all public institutions in that state, where the weights are the number of FTFT students paying the in-state rate.
- **Out-of-State Tuition Weighting:** The state-level out-of-state tuition is similarly weighted by the number of FTFT students paying the out-of-state rate.

**Mathematical Formula:**
State Weighted Tuition = Σ (Institutional Tuition_i × Institutional Weight_i) / Σ (Institutional Weight_i)

*Note: Since total residency-based enrollment for all undergraduates is not tracked annually in IPEDS, FTFT (First-time Full-time) counts are used as the standard research proxy for the institution's population distribution.*

## Outcome Variables
Consistent with the project's timeline requirements, data for 2024 is forward-filled to 2025 and 2026 to provide a complete 2012–2026 panel.

| Column | Description |
|:---|:---|
| `stabbr` | Two-letter state abbreviation. |
| `year` | Academic year (2012–2026). |
| `weighted_in_state` | State-average in-state tuition (weighted by in-state freshman enrollment). |
| `weighted_out_of_state` | State-average out-of-state tuition (weighted by out-of-state freshman enrollment). |
| `inst_count` | Number of public institutions included in the state average for that year. |
| `total_in_state_enr` | Total headcount of in-state freshman used as weight for that state/year. |
| `total_out_state_enr` | Total headcount of out-of-state freshman used as weight for that state/year. |
